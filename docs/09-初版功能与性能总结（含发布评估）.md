## 一、这是什么

一个 Windows 桌面应用：**接入你自己的大模型 API，在多个 Minecraft 服务器里同时跑可随时开关的陪伴型 bot** ——
陪你聊天、听你指挥、一起探险、帮你采集、帮你盖房、自己做工具。

| 项 | 现状 |
|---|---|
| 形态 | Electron 桌面应用（8 个页面，像素风），双击 `启动.cmd` |
| 代码量 | **23,795 行**（我们自己的：生产代码 13,266 + 自检/工具 6,598 + 文档 3,931） |
| 引擎 | vendored [Mindcraft](https://github.com/kolbytn/mindcraft)（MIT，© 2024 Kolby Nottingham），**源码零改动**，加固靠运行时注入 |
| 运行时 | 自带 Node **v22.23.3**（引擎硬要求 ≥22，系统 v24 不行）+ Temurin JRE 21（仅本地测试服需要） |
| 真机状态 | 已在用户的线上服务器（地址见 `runtime\config.json`，不公开）上跑通全部核心能力：1.21.1 / 离线登录可用 / **19ms** |
| 待用户确认 | 桌面**窗口**本身（本开发环境起不了 Electron，退出码 `0x80000003`）、真实大模型 API Key 的效果 |

## 二、功能清单

### 2.1 桌面应用（8 页）

| 页面 | 你能做什么 |

| **人格** | 陪伴风格（温柔陪伴 / 建造师等）逐条编辑，含"说话风格"与"能做什么/不做什么" |

| **皮肤** | 皮肤/模型设置 |
| **日志** | 事件流（门禁判定、引擎回执、错误）按 bot 分开，可导出 |

### 2.2 游戏内能力（玩家在聊天框说话）

| 你说 | bot 做什么 | 走的通路 | 实测证据 |
|---|---|---|---|
| `报一下坐标` / `看一下背包` | 用中文汇报坐标、群系、血量、饱食度、时间、天气、附近玩家 / 背包物品与装备 | 本地汇报 | 【实测】门禁→发言 **24~30ms**，0 token |
| `!stats` / `!inventory` | 同上（**直接敲引擎命令也接管了**，不再吐 15 行英文转储） | 本地汇报 | 【实测】与中文指令一字不差，0 token |
| `去砍点木头` | 自己找树、砍回指定数量（37 条中文方块词，认不出就退回大模型而不是猜） | 规则→引擎 | 【实测】砍回 10 个橡木，**0 token** |
| `跟着我` / `过来` / `停下` | 跟随、靠近、立刻停止 | 规则→引擎 | 【实测】四项唤醒规则全过；`!stop` 永远优先、零延迟 |
| `盖个房子` | 自己选址（19×19 内找平地、避开脚下）、核算材料、按序放置并补放 | 规则→本地建造器 | 【实测】3×3 完整小屋 23/23 块、**16 秒**、0 token；用另一个客户端逐格取证 |
| `四处走走` / `附近有铁矿吗` | 单方向探索 16~80 格（默认 32），分段短跳，沿途找矿并汇报坐标 | 规则→本地探险器 | 【实测】32 格 **9 秒**走完（改前进：48 格走 150 秒只挪 26 格） |
| `挖点石头` | 手里没镐 → 自己砍木 → 削木板 → 搭工作台 → 做木镐 → 挖石 | 规则→本地工坊 | 【实测】服务器当场发 `[Stone Age]` 成就，0 token |
| `做把铁镐` | 递归折账（铁镐→3 铁锭→3 原铁矿）→ 挖矿 → 补熔炉与燃料 → 烧炼 → 合成 | 规则→本地工坊 | 【实测】**45 秒**，服务器发 `[Acquire Hardware]`，0 token |
| `记住我喜欢钻石` / `你还记得…` | 写进/读出长期记忆（80 条上限、约定优先保留、中文二元组检索） | 本地记忆 | 【实测】四句话只用 **1 次**大模型调用 |
| `你好` / 有称谓的闲聊 | 人格化中文回复 | **大模型**（唯一花钱的通路） | 【实测】一次唤醒 **5137 token** |

合并成一句：**"下指令"这一类几乎不花钱，"闲聊"才花钱。**

### 2.3 中文通路是三层，不是一层

1. **规则层**（`runner/vocab.mjs` + `store.mjs` 的 12 条默认规则）：中文 → 引擎命令，命中即零 token。
   原则是"宁可认不出（退回大模型），也不猜错"。
2. **汇报层**（`runner/self-report.mjs`）：坐标/背包/群系/天气由我们本地念中文。
   原则是"读不到就不说，绝不补一个『大概是这样』的值"。
3. **翻译层**（`runner/engine-speak.mjs`）：引擎的英文回执逐行翻成中文
   （`Found non-destructive path.` → 「找到一条不用拆方块的路。」）。
   引擎源码里 **143 句**台词，**115 句有中文、28 句有意不翻**（都是我们没开放的能力，如种地、村民交易），**0 句漏网** —— 这条由 `tools\check-speak-coverage.mjs` 强制守住。
   同理，玩家能敲的 **55 条 `!命令`**：**2 条**被我们接管，**53 条**显式登记为"有意交给引擎"，**没登记的会报错**。

### 2.4 安全与权限（都实测过）

- **聊天门禁四规则**：只有主人能唤醒；必须带称谓（公屏）；私聊永远算；**每句都记账**（谁说的、放行还是拦、为什么）。
- **对陌生人不是静默无视**：未配置主人时会一次性提示"怎么把我认成你的"，之后按名单静默拒绝。
- **限流 + 每日 token 预算**：二者排在"唤醒判定"之前；但 `!stop` 排在它们**之前**（永远能用、零延迟）。
- **`blocked_actions` 双重作用**：既是安全闸门（不许乱拆别人家），也是 token 闸门（命令文档是提示词最大头）。
- 密钥：DPAPI 加密、明文不出主进程、界面掩码；自检会 SHA256 断言"跑完你的配置一个字节没变"。

| 盖一座 3×3 小屋 | **16 秒**（23 块） | 【实测】 |

### 3.2 花钱的地方（token 成本）

| 项 | 数值 | 来源 |
|---|---|---|
| 一次唤醒（"你好"） | **5129 输入 + 8 输出 = 5137 token** | 【实测】事件流 |
| 提示词构成 | 10,258 字符，其中**命令文档 6,999 字符（≈3500 token）是大头** | 【实测】逐段拆解 |
| 优化效果 | 砍掉 3 条危险/无用命令后 **5358 → 5137 token** | 【实测】 |
| 200k token / 日预算 | ≈ **39 次唤醒** | 【估算】按 5137 直接相除 |
| 采集 / 建造 / 探险 / 记忆 / 合成 / 烧炼 / 汇报 | **0 token** | 【实测】事件流里大模型调用 0 次 |
| 多 bot 并行 | A 放行 2 次累计 10,311 token（平均 5155/次），**跨服零 token 泄漏** | 【实测】 |
| 真实 API 的命中缓存/实际账单 | **接口会返回、已校准到一次最小请求**：`prompt=9 / completion=1`，`prompt_cache_hit_tokens=0` | 【实测】`tools\keyprobe` 真调一次（HTTP 200 / 187ms）；**整场唤醒的真实账单仍未测** |

### 3.3 质量与自检

- **17 套自动自检、一条命令约 1 分 50 秒**（`tools\run-all-tests.mjs`）：
  渲染八页 7.5s / 主进程 64 项 3.7s / 多 bot 53 项 57s / 多服务器 31 项 32s /
  采集词典 47 / 建造器 32 / 探险器 34 / 记忆 68 / 工坊 129 / 回执翻译 66 /
  本地汇报 69 / 首跑链路 51 / 大模型错误路径 71 / 三个静态检查。
- **715 项计数断言 + 渲染八页 + 三套静态/覆盖检查**，全绿。
- 每套必须打出自己的汇总行才算过 —— **只看退出码会把"什么都没跑"当成"全跑通了"**（这个假绿事故真的发生过）。
- 多 bot / 多服务器的自检会把数据目录整个重定向到沙箱，跑完 SHA256 断言**你的 `config.json` / `secrets.json` 一个字节没变**。

## 四、这个初版"结实"在哪（都是事故换来的）

不是功能多，而是**每条关键不变量都有东西守着**：

| 守的东西 | 谁在守 |
|---|---|
| 中文回执有没有漏翻 | `check-speak-coverage.mjs`（143 句全过一遍，缺一句就红） |
| 玩家能敲的命令有没有漏登记 | 同上第二段（55 条逐条登记，还会反查过期条目） |
| 有没有"用了却没 import"（会静默不吭声） | `check-imports.mjs`（`node --check` 看不见作用域） |
| 启动脚本的**字节**对不对（曾让你双击出一屏乱码） | `check-launchers.mjs` |
| 自检会不会连到你的线上服 | 启动进程**之前**读回已保存的配置逐个校验，非本机立刻退出 |
| 密钥是不是假的 | `looksLikePlaceholderKey()` + 界面三态 + `clean-fake-keys.mjs` |
| 提示词里有没有夹带明文密钥 | 渲染进程自检里的字符串断言 |

## 五、诚实的边界（发布前你也该知道）

**没验证的：**
1. **窗口本身**没在本环境确认过（Electron 起不来，退出码 `0x80000003`）。启动器链路是逐环验证的，但"窗口长什么样"只有你能看。
   （**后记**：`0x80000003` 的根因查清了 —— 是这台机器的 Chromium 沙箱起不来，启动器现在会自动降级重试，
   **窗口已经用命令行参数真的开出来过并截图取证**；但"双击 `启动.cmd` 也能开"仍要你自己确认一遍。）
2. **一次真实的大模型唤醒还没跑过。** 你的 Key **已经在 22:50 存进去了**，而且经真 Electron 探针实测
   **能调通**（`sk-…4874`、`HTTP 200 / 187ms`）。但上面 §3.2 的 5137 token / "39 次唤醒/日"
   仍然是**拆解估算**，不是账单 —— 校准它需要**真的喊它一声**（那时读 `prompt_cache_hit_tokens`
   才知道缓存能省多少）。探针只证明了"钥匙是真的、门是开着的"。
3. 多 bot 并行只测到**同机 2 台 / 2 台服务器**，没测 10 台的规模。

**已知的能力缺口（有意留的）：**
4. 种地、村民交易等 **28 句**引擎能力没开放（台词也没翻）。
5. **钻石镐造不出来**（铁/石/木三级全覆盖，钻石那级材料链没做）。
6. 玩家直接敲的 53 条 `!命令` 仍是**英文原样回执**（它们本来就是给模型看的内部命令）。
7. 引擎老报一个无害的 `PartialReadError`（`ArmorTrimMaterial` 解析，1.21 数据包问题，不影响游戏）。
