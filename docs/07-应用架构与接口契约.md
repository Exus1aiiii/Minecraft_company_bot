# 07 · 应用架构与接口契约

> 本文件是**主进程、渲染进程、引擎侧三方协作的唯一事实来源**。任何一方改接口，先改本文件。
> 目标：让"像素风 UI"和"进程管理/引擎接入"可以并行开发而不互相等待。

**运行时要区分两个根**：
- `APP_ROOT` = `app\`（Electron 自己的代码）

## 二、`AppConfig` —— 落盘在 `runtime\config.json`

```jsonc
{
  "version": 1,
  "llm": {
    "profiles": [
      {
        "id": "deepseek",                  // 稳定 id，bot 用它引用
        "label": "DeepSeek",
        "baseUrl": "https://api.deepseek.com/v1",
        "model": "deepseek-chat",
        "temperature": 0.7,
        "maxTokens": 800,
        "timeoutMs": 60000,
        "hasKey": true,                    // ← 只读，由主进程回填
        "keyHint": "sk-…3f2a"              // ← 只读，由主进程回填
      }
    ]
  },
  "servers": [
    {
      "id": "srv-local",
      "label": "本地测试服",
      "host": "127.0.0.1",
      "port": 25565,
      "version": "1.21.1",                 // 具体版本 或 "auto"
      "auth": "offline"                    // "offline" | "microsoft"
    }
  ],
  "bots": [
    {
      "id": "bot-xiaodou",
      "name": "Xiaodou",                   // ★ MC 账号名：必须 ^[a-zA-Z0-9_]{3,16}$
      "displayName": "小豆",                // 界面显示用的中文名
      "serverId": "srv-local",
      "llmProfileId": "deepseek",
      "enabled": false,                    // 面板开关的持久化状态
      "wakeNames": ["小豆", "xiaodou", "豆豆"],
      "owners": ["Steve"],                 // ★ 空数组 = 拒绝一切（fail closed）
      "rateLimitMs": 3000,
      "dailyTokenBudget": 200000,
      "personaId": "companion-gentle",
      "personaOverrides": { "systemPrompt": "" },   // 非空则整段覆盖预设
      "skin": { "model": "slim", "path": "", "enabled": false },
      "rules": [
        { "id": "follow", "enabled": true, "patterns": ["跟着我","跟紧我","跟我来"], "action": "followPlayer" },
        { "id": "stop",   "enabled": true, "patterns": ["停下","别动","站住","停"],  "action": "stop" },
        { "id": "come",   "enabled": true, "patterns": ["过来","来我这","来我身边"],  "action": "goToPlayer" }
      ]
    }
  ],
  "app": { "autoStartBots": false, "language": "zh" }
}
```

**密钥不在这里**。密钥单独存 `runtime\secrets.json`，值是 `safeStorage.encryptString(key).toString('base64')`，
键是 `llmProfileId`。`AppConfig` 允许回传前端时，**`hasKey` / `keyHint` 由主进程计算后填入，明文密钥永远不出主进程**。

`saveConfig()` 必须做校验并返回 `errors[]`（不抛异常）：
- `name` 不匹配 `^[a-zA-Z0-9_]{3,16}$` → `"MC 账号名只能是 3-16 位字母/数字/下划线"`
- `wakeNames` 为空 → `"必须至少有一个唤醒称谓"`
- `owners` 为空 → `"必须至少指定一个 owner，否则 bot 不会响应任何人"`
- `serverId` / `llmProfileId` 指向不存在的对象 → 对应错误
- `bots` 内 `id` 重复 / `servers` 内 `id` 重复

## 四、事件（子进程 → 主进程 → 界面）

**传输方式：文件，不用管道。** 子进程往 `runtime\logs\<botId>.jsonl` **追加**单行 JSON；
主进程用 `fs.watch` + 增量读取 tail 它。理由：本机沙箱下 `spawn` 的 piped stdio 会 EPERM，
而文件追加在沙箱内外都工作，且崩溃后日志仍在。

每行格式：

```jsonc
{"ts":1759600000000,"botId":"bot-xiaodou","type":"log","level":"info","line":"Xiaodou spawned."}
{"ts":...,"botId":...,"type":"gate","decision":"PASS","reason":"","from":"Steve","channel":"chat","text":"你好呀"}
{"ts":...,"botId":...,"type":"gate","decision":"BLOCK","reason":"rejectedNoWakeName","from":"Steve","channel":"chat","text":"大家晚上好"}
{"ts":...,"botId":...,"type":"llm","model":"deepseek-chat","ms":1420,"promptTokens":830,"completionTokens":52,"ok":true}
{"ts":...,"botId":...,"type":"mc","connected":true,"health":20,"food":20,"position":{"x":0,"y":64,"z":0},"dimension":"overworld","gamemode":"survival"}
{"ts":...,"botId":...,"type":"status","status":"running","pid":12345}
{"ts":...,"botId":...,"type":"error","line":"unsupported protocol version: 26.1"}
```

主进程把它们归一化后通过 `webContents.send('mcbot:event', ev)` 推给界面（见第五节 `onEvent`）。

## 五、`window.mcbot` —— 渲染进程唯一能用的接口
preload 通过 `contextBridge.exposeInMainWorld('mcbot', {...})` 暴露。**渲染进程没有 Node 权限**（`nodeIntegration:false`、`contextIsolation:true`、`sandbox:true`）。

```ts
interface McbotAPI {
  // ── 环境 ──
  getEnv(): Promise<{
    ok: boolean,
    projectRoot: string, nodePath: string, nodeVersion: string,
    engineDir: string, engineOk: boolean,
    javaPath: string | null,
    versions: { mineflayer: string, minecraftProtocol: string, minecraftData: string },
    problems: string[]                    // 人话描述，直接展示
  }>

  // ── 配置 ──
  getConfig(): Promise<AppConfig>                                  // hasKey/keyHint 已回填
  saveConfig(cfg: AppConfig): Promise<{ ok: boolean, errors: string[] }>

  // ── 密钥（明文只进不出）──
  setSecret(profileId: string, key: string): Promise<{ ok: boolean, error?: string }>
  clearSecret(profileId: string): Promise<{ ok: boolean }>
  testLLM(profileId: string): Promise<{ ok: boolean, ms?: number, model?: string,
                                         reply?: string, error?: string }>

  // ── 服务器 ──
  probeServer(o: { host: string, port: number, version?: string }):
    Promise<{ ok: boolean, version?: string, protocol?: number, motd?: string,
              players?: { online: number, max: number }, error?: string }>

  // ── bot 生命周期 ──
  listBots(): Promise<BotRuntime[]>
  startBot(id: string): Promise<{ ok: boolean, error?: string }>
  stopBot(id: string):  Promise<{ ok: boolean, error?: string }>
  restartBot(id: string): Promise<{ ok: boolean, error?: string }>
  stopAll(): Promise<{ ok: boolean }>

  // ── 观测 ──
  readLog(id: string, opts?: { lines?: number }): Promise<string[]>
  clearStats(id: string): Promise<{ ok: boolean }>

  // ── 长期记忆（botId 维度，落盘在 runtime\memory\<botId>.json）──
  getMemory(botId: string): Promise<{ ok: boolean, entries: MemoryEntry[], file: string }>
  addMemory(botId: string, text: string, kind?: MemoryKind):
    Promise<{ ok: boolean, count?: number, dup?: boolean, error?: string }>
  forgetMemory(botId: string, idOrText: string): Promise<{ ok: boolean, removed: number, count: number }>
  clearMemory(botId: string): Promise<{ ok: boolean, removed: number }>

  // ── 皮肤 ──
  pickSkinFile(): Promise<{ path: string, dataUrl: string } | null>
  readSkinFile(path: string): Promise<{ ok: boolean, dataUrl?: string, error?: string }>

  // ── 事件订阅（返回退订函数）──
  onEvent(handler: (ev: McbotEvent) => void): () => void

  // ── 杂项 ──
  openExternal(url: string): Promise<void>
  pickDirectory(): Promise<string | null>
  getVersions(): Promise<{ app: string, electron: string, chrome: string, node: string }>
}

type MemoryKind = 'fact' | 'promise' | 'place' | 'event'   // 事实 / 约定 / 地点 / 经历
interface MemoryEntry {
  id: string, ts: number, kind: MemoryKind,
  text: string, from: string | null, tags: string[]
}

type McbotEvent =
  | { type: 'runtime', bots: BotRuntime[] }                       // 1 Hz 全量快照
  | { type: 'log',     botId: string, ts: number, level: string, line: string }
  | { type: 'gate',    botId: string, ts: number, decision: 'PASS'|'BLOCK', reason: string,
                       from: string, channel: 'chat'|'whisper', text: string }
  | { type: 'llm',     botId: string, ts: number, model: string, ms: number,
                       promptTokens: number, completionTokens: number, ok: boolean }
  | { type: 'status',  botId: string, status: BotRuntime['status'], pid: number|null }
  | { type: 'notice',  level: 'info'|'warn'|'error', text: string }
```

## 六、像素风设计规范（渲染进程必须遵守）

**参考物是 Minecraft 的 GUI**，不是"复古网页"：深灰石板底 + 浅灰凸起边框 + 内凹输入框 + 硬阴影，**没有圆角、没有渐变、没有模糊**。

```css
:root {
  --mc-bg:        #1d1d21;   /* 窗口底 */
  --mc-panel:     #3c3c3c;   /* 面板底（MC 的 GUI 灰） */
  --mc-panel-dk:  #2b2b2b;   /* 内凹区（输入框/列表） */
  --mc-border-lt: #6f6f6f;   /* 凸起高光边 */
  --mc-border-dk: #1a1a1a;   /* 凸起暗边 */
  --mc-text:      #e0e0e0;
  --mc-text-dim:  #9a9a9a;
  --mc-green:     #5bd45b;   /* 在线 / 成功 */
  --mc-yellow:    #ffd83d;   /* 警告 / 待机 */
  --mc-red:       #e04b4b;   /* 错误 / 离线 */
  --mc-gold:      #f5c542;   /* 强调 / 标题 */
  --mc-accent:    #4a8f3c;   /* MC 的草绿按钮 */
  --mc-accent-lt: #5fae4c;
}
```

**凸起边框**（按钮、面板）用双层 border 实现，不要用 border-radius / box-shadow 糊：
```css
.raised { border-top:2px solid var(--mc-border-lt); border-left:2px solid var(--mc-border-lt);
          border-right:2px solid var(--mc-border-dk); border-bottom:2px solid var(--mc-border-dk); }
.sunken { border-top:2px solid var(--mc-border-dk); border-left:2px solid var(--mc-border-dk);
          border-right:2px solid var(--mc-border-lt); border-bottom:2px solid var(--mc-border-lt); }
```

**字体**：像素中文字体体积大，先不内置。用这个栈，并**要求所有数字与英文标签天然对齐**：
```css
--font-pixel: "Fusion Pixel", "Zpix", "Unifont", "Microsoft YaHei", "微软雅黑", monospace;
```
正文用 `font-size:14px; letter-spacing:0.5px;`；标题用 `--mc-gold` + `text-shadow: 2px 2px 0 #000`。
**禁止**平滑过渡动画（`transition` 只允许 `background-color 80ms`）；hover 用换色不用缩放。

**布局**：左侧竖排图标+文字导航（宽 168px），右侧内容区。
导航项：`机器人 / 服务器 / 模型 / 人格 / 皮肤 / 日志 / 环境`。
顶部一条 32px 状态条：左边是应用名，右边是"当前在线 bot 数 / 总 token / 设置齿轮"。

**每一项都要能在 1024×700 的最小窗口下正常显示**，内容区可滚动。

## 七、硬约束（违反即返工）

1. **渲染进程不用打包器、不用 npm 包、不引 CDN**。纯 `<script type="module">` + 相对路径 import。离线必须能跑。
2. **不安装任何 npm 依赖到 `app/`**，除了 `electron` 本身（devDependency）。
3. **渲染进程不能碰 Node API**：没有 `require`、`fs`、`path`、`process`。要什么就走 `window.mcbot`。
4. **所有界面文案用中文**（这是给中文用户的本土软件），代码注释也用中文。
5. **不调用 `present`、不写 README、不改 `docs/`**（那是父会话的事）。
6. 代码里的 `console.log` 保留但用 `[ui]` 前缀。
7. `app/renderer/` 之外的文件一律不改。

## 九、人格面具契约（`runner/personas/`）

每个预设是一个 JSON：

```jsonc
{
  "id": "companion-gentle",
  "label": "温柔的陪伴者",
  "description": "一句话说明这个面具的性格，给用户看",
  "tags": ["陪伴", "温和"],
  "traits": {
    "tone": "温柔、耐心、口语化",
    "verbosity": "short",              // short | medium | long
    "humor": 2,                         // 0-5
    "initiative": 2,                    // 0-5：会不会主动提议做事
    "addressStyle": "叫玩家名字的后两字，或用「你」"
  },
  "systemPrompt": "完整的中文人设提示词，含：身份、性格、说话方式、禁止事项、如何回应指令",
  "examples": [
    { "user": "小豆 你好呀", "assistant": "欸，我在呢！" }
  ]
}
```

`runner/personas/index.mjs` 导出：
- `listPersonas()` → 去掉 `systemPrompt` 的元数据数组（给 UI 列卡片）
- `getPersona(id)` → 完整对象
- `buildSystemPrompt(persona, ctx)` → 把 `ctx`（`{botDisplayName, ownerName, language}`）插进 `systemPrompt` 的 `{{...}}` 占位符

预设至少覆盖：`companion-gentle`（温柔陪伴）、`companion-lively`（活泼损友）、`butler`（稳重管家）、`explorer`（冒险搭档）、`builder`（建筑师助手）、`quiet`（少话）。

**提示词必须写清**：只输出中文；不要输出 `!命令` 之外的动作描述；被叫到时才说话；不确定就说不确定；不要假装做过没做的事。
